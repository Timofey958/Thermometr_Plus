# Termometr Plus
Термометр на базе Arduino Uno + LCD Keypad Shield + DHT22

## Что особенного
1. Есть значки температуры и влажности
2. Есть регулировка яркости кнопочками

## Что появится в будущем
1. Средняя температура и влажность за время работы
2. Время, за которое проработало устройство

## Подключение
LCD Keypad Shield - на Arduino Uno    
DHT22 (уже распаянный модуль) - 
1. Плюс к 5v
2. Out к пину 2 
3. Минус к GND

## Загрузка кода
В файле binaries находится файл firmware.hex, его надо скачать. После, перейдите на сайт https://ardublock.ru/hex/, выберите скачанный файл, выбирайте Arduino new bootloader и порт, где подключена Arduino
